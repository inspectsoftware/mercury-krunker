The first public Mercury Client: a Krunker client on Chromium (CEF) with a Rust host. **Pre-release:** please
report anything that breaks, and use General → Diagnostics report to attach the details.

**Install:** run `MercuryClient-Setup-0.3.0.exe`. It installs for your user only (no admin rights) and updates
itself. Windows SmartScreen may warn because the installer isn't signed yet: More info → Run anyway.

## What's in it

- **Settings:** in Krunker's own settings window, last tab "Mercury". F8 opens it, and it shows up in Krunker's
  settings search.
- **Engine:**
  - uncapped FPS, with Krunker's own aim freeze fix on by default;
  - graphics backend (D3D11, D3D11on12, OpenGL, Vulkan), color profile, custom Chromium flags;
  - optional waitable swap chain.
- **Present hook** (GPU process):
  - an exact FPS limit that also keeps a GPU-bound PC from collapsing to single-digit FPS;
  - a present FPS counter;
  - MMCSS;
  - the OBS shared texture.
- **Performance:**
  - a URL blocklist (ads, trackers, widgets), editable;
  - an audio stutter fix;
  - Laptop Power Boost, the GPU preference and an NVIDIA driver profile (each opt-in and undone when you turn it
    off);
  - HighQoS, a CPU throttler, a Krunker performance preset and a system check panel.
- **Input and HUD:** raw mouse input, keystrokes overlay, HUD editor (drag, resize, hide, snapping), menu timer.
- **Look:**
  - resource swapper and CSS manager (both with in-client managers);
  - cleaner menu, classic menu, Mercury look, Mercury icons, motion blur.
- **Chat and social:**
  - better chat, chat logs (F1), clan colors, match end message per account;
  - Discord Rich Presence (needs an application ID), now playing;
  - mod downloads and game links in the game window;
  - battle pass claim-all, rank progress and nukes.
- **Matchmaking and ranked:**
  - matchmaker (F6, lowest ping first), real ping per region and in Find Game;
  - ranked queue window with a match-found sound, ranked alert, ranked rating.
- **Accounts and market:**
  - an encrypted account manager (Ctrl+Alt+1/2/3; try it on an alt first);
  - a read-only market analyzer with a watchlist.
- **Streaming:** an OBS capture plugin (see README), streamer mode (Ctrl+Shift+S).
- **Userscripts:** Crankshaft and idkr formats, with a manager. Every script starts off. Class Roulette example.
- **Support:**
  - a diagnostics report;
  - a crash finder (finds the module behind a problem);
  - safe mode;
  - a crash log;
  - auto-updates.

Mercury reads no hidden game state and plays nothing for you. What each feature touches, measured against Krunker's
rules: [docs/rules.md](https://github.com/inspectsoftware/mercury-krunker/blob/main/docs/rules.md).
