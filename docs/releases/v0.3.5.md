**Pre-release.** A fix to [v0.3.4](https://github.com/inspectsoftware/mercury-krunker/releases/tag/v0.3.4).

- **The window works like a normal window:** it opens maximized (or as set in F8 → General → Start as) and has
  minimize and maximize buttons and resizable edges again. Before, the window could not be maximized, minimized or
  resized at all, so "Maximized" did nothing.
